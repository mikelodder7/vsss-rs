# Security Policy

## Supported versions

Security fixes are applied to the latest release. Users should upgrade to the
newest compatible version before reporting an issue that may already have been
resolved.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability.

Email Michael Lodder at `redmike7@gmail.com` with:

- A description of the issue and its potential impact.
- The affected version, feature set, and platform.
- Reproduction steps or a proof of concept, when available.
- Any suggested mitigation or fix.

Please allow reasonable time to investigate and coordinate a release before
public disclosure. Receipt will be acknowledged as soon as practical.
